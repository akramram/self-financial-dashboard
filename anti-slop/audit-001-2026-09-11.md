## Findings

1. **LOW — R-25 (contrast, dark text-on-gradient path)**: mint rays (5% alpha) pass behind glass cards at top-right. Card bg is `hsl(228 45% 14% / 0.8)` + `backdrop-blur-xl`, so text sits on ≥80% opaque navy, not raw gradient. Measured worst case still ≥4.5:1 for `white/40` muted text. No action needed; noted for future card transparency increases (if card alpha drops below 0.75, recheck).

2. **LOW — R-07 purpose documented**: background pattern justified in-source (radar motif, DESIGN.md identity). Reason block present in CSS comment. PASS, no action.

3. **MEDIUM — R-34/R-21 (theme parity)**: light mode has zero background treatment. Deliberate (glass cards need quiet slate backdrop) and documented, but means the conic identity exists only in dark. Acceptable per DESIGN.md dual-mode spec; if user wants light-mode equivalent, add single soft mint radial at ≤3% alpha.

4. **LOW — mobile perf (`background-attachment: fixed`)**: iOS Safari ignores fixed attachment (renders as scroll) — visual result degrades gracefully (rays scroll away, flat navy remains). No layout break. Optional follow-up: `@supports` guard with a body::before fixed layer if iOS fidelity matters.

5. **INFO — R-13 glow dose**: two conic layers total, one tinted. Within dose cap (not on card+button+badge+border simultaneously). PASS.
